# MP-Commander (Multi-Pane Commander)

Double Commander 스타일의 멀티 패널(2·3·4·6·8창) 파일 매니저. WPF(.NET Framework 4.7.2) + C++ 네이티브 모듈(FmCore.dll).

📖 **[사용자 설명서](docs/manual/MANUAL.md)** · **[User manual (English)](docs/manual/MANUAL.en.md)** (기능 설명 + 목적별 활용, 화면 캡처 포함) · 📝 [변경 내역](CHANGELOG.md)

## 빌드 / 배포

```powershell
.\build.ps1                 # Release 빌드 (C++ FmCore → WPF 앱)
.\build.ps1 -Publish        # .\publish 에 실행 파일 3개 복사 (약 0.4 MB)
```

- 빌드에 필요: Visual Studio 2022 (C++ 데스크톱 워크로드), .NET SDK (8 이상, 빌드 도구로만 사용)
- Visual Studio 에서는 `MP-Commander.sln` 을 열고 x64 로 빌드 (FmCore 가 먼저 빌드됨)
- FmCore 는 정적 CRT(/MT) 로 빌드되어 VC++ 재배포 패키지가 필요 없다
- 배포본: `MP-Commander.exe` + `MP-Commander.exe.config` + `FmCore.dll` 세 파일(약 0.4 MB)을 같은 폴더에 두면 끝.
  사용 설명서는 `manual\` 폴더(MANUAL.md + 화면 캡처)로 함께 들어 있다 (없어도 실행에는 상관없고, F1 은 GitHub 의 설명서를 연다)
- 실행 환경: .NET Framework 4.7.2 가 기본 내장된 Windows 10 1803 이후(LTSC 2019 포함)·Windows 11 은 추가 설치 없음.
  그보다 오래된 Windows 10 은 .NET Framework 4.7.2 이상 설치 필요.

```

```

## 네트워크 지연 대응 (먹통 방지)

1. **UI 스레드에서 파일시스템 API 를 호출하지 않는다.** 모든 I/O 는 전용 스레드에서 돈다.
2. **사전 통신 체크**: UNC 경로·네트워크 드라이브는 접근 전에 서버의 445/139 포트로 TCP 연결을 시도, **2초** 안에 응답이 없으면 바로 오류 표시. 결과는 서버별 캐시(정상 30초, 실패 5초).
3. **진행 워치독**: 폴더 열거 중 항목이 **5초**(로컬 10초) 동안 하나도 안 들어오면 타임아웃으로 확정하고 `CancelSynchronousIo` 로 막힌 호출을 끊는다. 그래도 안 풀리는 스레드는 버린다.
4. **파일 찾기**: C++ 워커마다 I/O 시작 시각을 기록, 한 호출이 5초를 넘으면 그 스레드의 I/O 만 취소하고 다음 폴더로 진행.
5. **복사/이동**: 진행이 5초 멈추면 진행 창에 경고, [취소]는 막힌 I/O 까지 끊는다.
6. 실패한 패널은 이전 목록을 유지하고 노란 오류 줄에 [다시 시도] 를 보여 준다.

`tests/IoProbe` 측정 결과 (이 PC):

| 경로 | 결과 |
|---|---|
| `\\10.255.255.1\share` (응답 없는 IP) | 2.05초 후 연결 불가 |
| `\\no-such-host-xyz\share` | 1.5초 후 연결 불가 |
| 응답 없는 파이프 읽기 (`--hang`) | 3초 타임아웃에 정확히 끊김 |
| `C:\Windows\WinSxS` (29,848개) | 118 ms |

## 보기 (F3)

- 텍스트(인코딩 자동: UTF-8 / UTF-16 / CP949), 16진수(H), 이미지. W: 줄 바꿈, Esc: 닫기.
- **가상 텍스트 보기** (`Views/VirtualTextView.cs`): 보이는 줄만 그린다. 파일 크기와 상관없이 바로 열린다 (300 MB 첫 화면 0.2초 안팎).
  - **C++ `FmText.cpp`**: 백그라운드 스레드가 줄 시작 위치 색인을 만든다 (memchr, 약 1 GB/s). 임의 위치 읽기, 바이트 위치 → 줄 번호.
  - `IO/TextFileSource.cs`: 256줄 블록 단위로 읽어 캐시(LRU). 그리기는 캐시만 쓰고 없으면 읽기 스레드에 맡긴 뒤 다시 그린다 → 느린 네트워크에서도 UI 가 멈추지 않는다.
  - 찾기 — 일반 문자열: **C++** 이 파일 인코딩 바이트로 훑어 (줄, 개수) 를 주고(300 MB 0.2~0.7초), C# 한 스레드가 그 줄만 디코딩해 확인·미리보기를 만든다.
    정규식: C# 여러 스레드 (`IO/LargeTextSearch.cs`, 4 MB 블록 병렬).
  - 글자 단위 선택(끌기·Shift+클릭·더블클릭 단어·Ctrl+A) + Ctrl+C: FormattedText 의 글자 위치로 이분 탐색해 열을 찾는다.
  - 찾기는 입력이 0.5초 멈춘 뒤 시작. 찾기·확인·정규식 스레드는 BelowNormal 우선순위 (C++ 스레드도) → 찾는 중에도 스크롤·선택이 부드럽다.
    사용자가 스크롤·클릭하면 찾기가 화면을 옮기지 않는다.
  - 찾은 줄 목록은 직접 그리는 가상 목록(`Views/HitListView.cs`)에 **끝에 덧붙이기만** 한다 → 수십만 줄도 선택·스크롤이 유지되고 깜박이지 않는다. 개수 칸은 폭 고정.
  - 측정 (300 MB, 237만 줄): 열기 0.2초, 거의 모든 줄이 걸리는 찾기('INFO') 중 UI 응답 평균 1.4 ms·최대 48 ms.
  - 점검: `IoProbe --text-source` (색인·임의 줄·C++ 찾기·취소, UTF-8 300 MB / CP949 / UTF-16), `IoProbe --large-search` (정규식 경로).
- **찾기**: 위쪽 찾기 칸(Ctrl+F)에 입력하면 바로 찾는다. **F3 다음 / Shift+F3 이전** (Enter·버튼도 같음). 찾을 말이 없으면 F3 은 닫기.
  - 옵션: **대소문자 구분**, **정규식**(.NET Regex, `^ $` 는 줄 단위 — `\r\n` 줄 끝도 맞음, 잘못된 식은 오류를 보여 줌).
  - 본문에서 지금 찾은 말은 주황 상자로 표시하고 그 줄로 스크롤한다.
  - 아래 칸(경계선을 끌어 크기 조절)에 **찾은 줄이 모두** 줄 번호·개수와 함께 나오고, 찾은 말은 노란색으로 칠한다. 줄을 고르면 본문이 그리로 간다.
  - 그 아래 칸(경계선으로 크기 조절)에는 **고른 줄 전체가 자동 줄 바꿈**으로 나오고, 찾은 말은 노란색(지금 것은 주황)으로 칠한다.
- **파일 찾기(Alt+F7)** 결과에서 F3 으로 열면 '포함 텍스트'(대소문자 구분·정규식 설정 포함)로 바로 찾은 상태로 열린다.
- 뷰어는 파일을 읽자마자 닫으므로(읽기·쓰기·삭제 공유), 열어 둔 동안에도 다른 프로그램이 그 파일에 쓰거나 이름을 바꾸거나 지울 수 있다.

## 툴바 검색 상자

- 툴바 오른쪽 끝. 입력이 0.3초 멈추면 Everything 으로 모든 드라이브에서 찾아 상자 아래 펼침 목록(Popup)에 — **Enter** 면 맨 위(↑↓ 로 고른) 항목을 현재 패널에서 보여 준다 (파일은 폴더 + 커서, 폴더는 안으로).
  순서: 이름 같음 → 그 말로 시작 → 폴더 → 짧은 경로. Everything 이 없으면 Enter 는 파일 찾기 창(현재 패널 폴더).
- Everything 과는 SDK DLL 없이 WM_COPYDATA IPC 로 통신 (`IO/Everything.cs`). 속성은 묻지 않는다 (Everything 기본 설정에서 색인되지 않아 결과마다 디스크를 읽음).

## 파일 찾기 (Alt+F7)

- 시작 폴더, 파일 이름(와일드카드 없으면 부분 일치), **포함 텍스트**, 하위 폴더 / 대소문자 구분 / **정규식** / 숨김 파일.
- 여러 스레드(C++)로 찾고, 느린 네트워크에서는 I/O 하나가 5초를 넘으면 끊고 넘어간다.
- 포함 텍스트: 보통은 C++ 이 UTF-8 / ANSI(CP949) / UTF-16 바이트로 찾는다.
  **정규식**을 켜면 C++ 이 파일을 읽어 인코딩(BOM, UTF-8, CP949, UTF-16)을 판별해 줄 단위 텍스트로 넘기고 .NET 정규식으로 판정한다 (뷰어와 같은 규칙: `^ $` 줄 단위).
- 결과의 **찾은 말 / 줄** 열: 파일마다 포함 텍스트가 나온 횟수와 그 줄 수 (백그라운드에서 셈, 파일당 5초 제한, 64 MB 초과는 `-`). 상태 줄에 합계.
- 결과에서 Enter / 더블클릭: 패널에서 보기, F3: 뷰어 (포함 텍스트로 찾은 상태).
- **Ctrl+Alt+F7**: [Everything](https://www.voidtools.com/) 검색 창을 현재 폴더로 연다 (`Everything.exe -path 폴더`). Everything.exe 는 프로그램 폴더 → 실행 중인 프로세스 → 레지스트리(App Paths, 제거 정보) → Program Files 순으로 찾는다.

## 폴더 비교 · 동기화 (Shift+F2)

- `IO/FolderSync.cs`: `FolderCompare.Run` 이 두 폴더를 하위까지 읽어 비교 (크기 + 수정 시각 2초 오차, 크기 같고 1 MB 이하는 내용 비교, 한쪽에만 있는 폴더는 맨 위 하나로 묶음, 제외 이름은 PathMatchSpec).
- `Plan(SyncMode)`: 양쪽 똑같이 / A→B·B→A 최신만 / A·B 만 남기기. `Advice()`: 한쪽에만 있는 것·더 최신인 것의 수로 남길 쪽 조언.
- `FolderSyncOperation`: 복사(FmCopyFile, 수정 시각 유지) 먼저, 삭제는 마지막에 한 번에 휴지통으로. 창은 `Views/FolderSyncWindow`.
- 점검: `IoProbe --folder-sync`.

## 편집기 (F4)

- **텍스트 편집기** (`Views/TextEditorWindow`): [AvalonEdit](https://github.com/icsharpcode/AvalonEdit) 6.3 (MIT).
  NuGet 으로 받아 **실행 파일 안에 리소스로 넣고**(`EmbeddedResource`, `ExcludeAssets="runtime"`), `App.ResolveEmbedded`(AssemblyResolve)가 처음 쓸 때 불러온다 — 배포 파일은 그대로 3개.
  줄 번호, 문법 색(`HighlightingManager.GetDefinitionByExtension`), SearchPanel 찾기, 바꾸기·줄 이동 막대. 인코딩·줄바꿈 유지, 저장은 임시 파일 → `File.Replace` (`IO/TextFileCodec.cs`).
- **CSV 편집기** (`Views/CsvEditorWindow`, `IO/CsvDocument.cs`): DataGrid + 줄 객체의 인덱서 바인딩(`[i]`). RFC 4180 파서, 칸마다 '따옴표였는지' 를 기억해 고치지 않은 칸은 바이트 그대로 저장.
- Shift+F4 = 외부 편집기. 설정 `Editor` 가 비었거나 `notepad.exe`(예전 기본값)면 내장.
- 라이선스 고지: `docs/THIRD-PARTY-NOTICES.txt` (배포본 `manual\`).
- 점검: `IoProbe --csv`.

## 클립보드 (Ctrl+C / Ctrl+X / Ctrl+V)

- 표시한 항목(없으면 커서 항목)을 Windows 표준 형식으로 클립보드에 넣는다 → 탐색기에 붙여넣을 수 있고, 탐색기에서 복사한 파일도 패널에 붙여넣을 수 있다.
- 붙여넣기는 활성 패널 폴더로, 복사와 같은 진행 창·덮어쓰기 확인을 쓴다. 잘라내기였으면 이동하고 클립보드를 비운다.
- 같은 폴더에 붙여넣으면 탐색기처럼 `이름 - 복사본`, `이름 - 복사본 (2)` 로 만든다.
- 휴대폰·FTP·WebDAV 파일은 MP-Commander 패널끼리 주고받을 수 있다 (탐색기로는 안 됨).
- 경로 입력란·명령줄에서는 평소처럼 글자 복사·붙여넣기가 된다.

## 차단 해제 (툴바 자물쇠 버튼, Ctrl+Shift+U)

인터넷에서 받은 파일에 Windows 가 붙이는 표시(Zone.Identifier, "Mark of the Web")를 지운다.
파일 속성의 '차단 해제', PowerShell 의 `Unblock-File` 과 같다. 실행 시 보안 경고와 차단이 사라진다.

- 대상: 표시한 파일·폴더, 없으면 커서 항목, 그것도 없으면 현재 폴더.
- 버튼을 누르면 설정 창이 열린다: **하위 폴더까지**(기본 켬), **폴더 안에서 처리할 파일 형식**(기본 exe, dll / 체크박스 + 기타 형식 / 모든 파일).
  설정은 `settings.ini` 의 `[Unblock]` 에 저장된다.
- 직접 고른 파일은 형식과 관계없이 처리하고, 형식 조건은 폴더 안의 파일에만 적용한다.
- 읽기 전용 파일도 처리하고 읽기 전용 속성은 그대로 둔다. 정션·심볼릭 링크 폴더는 따라가지 않는다.
- 결과: 상태 표시줄에 "차단 해제 n개 (검사 m개, 원래 차단 없음 k개)", 실패가 있으면 목록을 보여 준다.
- 시험: `IoProbe --unblock`.

## 자동 새로고침

폴더 안의 파일이 추가·삭제·이름 변경되면 목록이 저절로 바뀐다 (커서와 선택 표시는 유지).

| 경로 | 방식 | 반영까지 |
|---|---|---|
| 로컬 드라이브 (C:, USB) | Windows 변경 알림 | 1초 이내 |
| 네트워크 공유 (`\\서버\공유`, SMB 연결 드라이브) | 변경 알림(서버가 응답할 때만 3초 제한으로 연결) + 5초마다 확인 | 약 2~5초 |
| WebDAV 연결 드라이브, FTP·WebDAV 연결, 휴대폰 | 8초마다 확인 (알림이 없음) | 최대 8초 |

- 주기 확인은 목록을 다시 읽어 실제로 달라졌을 때만 화면을 바꾸고, 실패해도 오류를 띄우지 않고 다음 주기에 다시 본다.
- 큰 폴더·느린 서버는 확인 간격이 자동으로 늘어난다 (읽는 시간의 4배, 최대 1분). 숨겨진 패널과 최소화된 창은 확인하지 않는다.
- 경로 입력란·명령줄에 입력 중이면 자동 새로고침이 포커스를 가져가지 않는다.
- 시작 경로를 명령줄로 줄 수 있다: `MP-Commander.exe "C:\작업" "\\nas\share" ftp://서버` (패널 1, 2, 3...).

## 패널 배치 / 툴바

- 2창·3창은 가로 한 줄, 4창은 2×2, 6창은 2×3, 8창은 2×4. 패널 번호는 위 줄 왼쪽부터 1, 2, 3...
- 툴바는 아이콘만 표시한다 (마우스를 올리면 설명과 단축키). 배치 버튼은 격자 모양 아이콘.
- 목록 글씨 크기는 툴바의 글꼴 버튼(작게/보통/크게) 또는 Ctrl+= / Ctrl+-, 설정 파일 `FontLevel` (0~2) 에 저장.

## 3창 이상 동작

- 활성 패널은 파란 테두리, **대상 패널**(F5/F6 의 기본 목적지)은 주황 테두리와 "대상" 표시.
  대상은 직전에 활성이던 패널이고, Ctrl+Shift+숫자로 고정할 수 있다. 2창에서는 항상 반대편.
- **드래그 앤 드롭**: 파일을 다른 패널(또는 그 안의 폴더 위)에 놓으면 복사/이동 메뉴가 뜬다.
  Ctrl 을 누른 채 놓으면 바로 복사, Shift 는 바로 이동. 탐색기와도 주고받을 수 있다.
- **탐색기의 가상 파일**: 탐색기에서 휴대폰(MTP) 저장소·zip 안·Outlook 첨부를 끌어 놓거나 복사해 Ctrl+V 하면 PC 폴더로 복사한다
  (`FileGroupDescriptorW` + `FileContents` 스트림, `IO/VirtualFileDrop.cs`). 목록은 놓는 순간 UI 스레드에서 읽고, 내용은 데이터 개체를 작업 스레드로 마샬링해 읽는다.
  원본이 비동기 추출(IDataObjectAsyncCapability)을 지원하면 그것을 써서 탐색기가 기다리지 않는다.

## 명령줄 (하단)

- 프롬프트에 **활성 패널의 폴더**가 표시되고, 입력한 명령은 그 폴더를 작업 폴더로 실행된다.
- Enter: 프로그램(.exe)은 바로 실행, 문서·바로 가기는 연결 프로그램으로, 내부 명령(dir, copy, echo...)과 배치 파일은 cmd 창에서 실행하고 창을 남긴다.
- Shift+Enter: 항상 cmd 창에서 실행하고 창을 남긴다.
- `cd 경로`, `cd..`, `cd \`, `D:` 는 실행하지 않고 활성 패널을 이동한다 (`%TEMP%` 같은 환경 변수도 됨).
- ↑↓ 또는 Alt+↓ 로 이전 명령 (최근 50개, settings.ini `[CommandHistory]`), Esc 는 지우고 목록으로.
- 네트워크 폴더는 실행 전에 서버 응답을 확인하고, UNC 폴더에서 cmd 를 쓸 때는 `pushd` 로 임시 드라이브를 잡는다. 휴대폰 폴더에서는 실행하지 않는다.

## 오른쪽 버튼 메뉴

- 위쪽: MP-Commander 명령 (보기, 편집, 대상 패널로 복사/이동, 이름 바꾸기, 경로·이름 복사, 압축/풀기).
- 아래쪽: **탐색기와 같은 셸 메뉴** — 7-Zip·반디집 압축, 보내기, 연결 프로그램, 잘라내기/복사, 삭제, 속성, Git 등 설치된 확장이 그대로 나온다. Shift 를 누른 채 열면 확장 메뉴(경로로 복사 등)도 보인다.
- 빈 곳을 누르면 폴더 메뉴 (새 폴더, 새로고침, 경로 복사, 터미널 + 셸의 붙여넣기·속성 등).
- 표시된 항목(빨간색) 위에서 누르면 표시된 항목 전체, 아니면 누른 항목 하나가 대상이다.
- 네트워크 서버가 응답하지 않으면 셸 메뉴는 빼고 앱 명령만 보여 준다(셸 확장이 멈추는 것 방지). 휴대폰 경로도 앱 명령만.
- 셸 명령 실행 뒤에는 패널을 자동으로 새로고침한다.

## 압축 (Alt+F5 / Alt+F9)

- 압축 (Alt+F5, 툴바 버튼): 표시한 항목(없으면 커서 항목)을 **대상 패널 폴더**에 압축한다 (Double Commander 와 같음). 대상 패널이 원격이면 현재 폴더.
  창에서 경로, 형식(**7z** / ZIP), 압축 수준(저장·빠르게·보통·최고)을 고른다. 형식·수준은 기억한다 (settings.ini `[Pack]`).
- 폴더 하나만 골랐을 때는 **최상위 폴더 제외 — 안의 내용만 압축** 을 켤 수 있다. 풀면 폴더 없이 내용이 바로 나온다 (선택도 기억).
- 7z 는 **7-Zip** 으로 만든다. 프로그램 폴더의 `7za.exe`/`7z.exe` → 레지스트리의 7-Zip 설치 경로 → Program Files → PATH 순서로 찾는다.
  7-Zip 이 없으면 7z 선택이 꺼지고 ZIP 만 된다.
- ZIP 은 내장: 이름을 UTF-8 로 저장해 어느 프로그램에서도 한글이 깨지지 않는다.
- 둘 다 임시 파일에 쓰고 완성되면 이름을 바꾸므로 취소해도 깨진 압축 파일이 남지 않는다. 진행 창·취소·멈춤 경고는 복사와 같다.
- 풀기 (Alt+F9, 툴바 버튼): 표시한 압축 파일들(없으면 커서의 압축 파일)을 **대상 패널 폴더**에 푼다. 여러 개를 한 번에 풀 수 있다.
  - **압축 파일마다 그 이름의 폴더를 만들어 풀기** 가 기본 (예: `자료.7z` → `자료\`, `x.tar.gz` → `x\`). 끄면 풀 위치에 바로 푼다.
  - 같은 이름의 파일은 덮어쓰기(기본) 또는 건너뛰기. 두 옵션 모두 기억한다.
  - ZIP 은 내장: UTF-8 표시가 없는 이름은 UTF-8 이면 그대로, 아니면 CP949 로 읽고, 폴더 밖으로 나가는 항목(`../`)은 막는다.
  - 7z·RAR·TAR·GZ·XZ·CAB·ISO 등은 7-Zip 으로 푼다. `.tar.gz`·`.tgz`·`.tar.xz` 등은 한 번에 끝까지 푼다.

## 백업 후 복사 (Backup-Copy, Ctrl+B)

프로그램 업데이트처럼 **대상 폴더의 옛 파일을 백업해 두고 새 파일로 바꿀 때** 쓴다. 툴바(폴더+시계), Ctrl+B, 오른쪽 버튼 메뉴.

- 원본 = 활성 패널에서 표시한 항목(없으면 커서 항목), **대상 = 다른 패널의 현재 폴더**. 활성 패널에 표시가 없고 다른 패널에만 있으면 그쪽이 원본.
  준비 창에 원본·대상 폴더와 **⇄ 방향 바꾸기** 버튼.

1. 원본 패널에서 파일·폴더를 고르고 실행 → 대상 패널 폴더로 복사할 계획을 만든다 (덮어쓸 파일 / 새 파일 수).
2. 준비 창: **대상 파일을 쓰고 있는 프로그램**을 찾는다 (Windows Restart Manager — 실행 중인 exe, 불러온 DLL, 열린 파일 + 실행 파일 경로 비교).
   - 목록에서 [닫기 요청](창 닫기, 저장 확인은 그 프로그램에서) / [강제 종료] / [다시 확인]. 직접 닫고 [다시 확인] 해도 된다.
   - 백업 위치(기본 `backup`, 상대 경로면 대상 폴더 아래, 절대 경로도 가능)와 **폴더 이름 앞말**을 고른다 → `backup\[앞말]20261009_0947\` (같은 분에 또 하면 `_2`).
   - **복사가 끝나면 닫았던 프로그램 다시 실행** (기본 켬): 같은 실행 파일·인자로 다시 띄운다 (서비스·MP-Commander 자신은 제외).
3. 백업: 대상에 이미 있는 같은 이름의 파일을 백업 폴더에 **같은 폴더 구조로** 먼저 복사한다. 백업에 실패한 파일은 덮어쓰지 않는다.
4. 복사: 원본을 대상에 덮어쓴다. 파일이 사용 중이면 창이 뜬다 —
   **프로그램 닫고 다시 시도 / 강제 종료 후 다시 시도 / 다시 시도 / 이름 바꿔 교체 / 건너뛰기 / 중단**.
   '이름 바꿔 교체'는 옛 파일을 `이름.old-시각` 으로 비켜 두고 새 파일을 놓는다 (실행 중인 exe·dll 도 가능, 다시 시작하면 적용).
5. 백업 폴더에 `backup-copy.log` (원본·대상·백업·복사·닫은 프로그램·실패 기록).

- 설정 창(툴바 톱니바퀴)이나 settings.ini `[BackupCopy]` 의 `Root`, `Prefix`, `Restart` 로 기본값을 바꾼다.
- 핵심 동작(`IO/BackupCopy.cs`, `IO/RunningProcesses.cs`)은 화면과 분리돼 있어, 나중에 스크립트/명령줄로 "최신 버전 찾기 → 백업 후 복사 → 다시 실행" 을 자동화할 때 그대로 쓴다.
- 점검: `IoProbe --backup-copy` (실행 중인 exe 감지, 백업·복사, 닫기 실패 → 강제 종료, 이름 바꿔 교체, 다시 실행, 기록).

### 복원 (Ctrl+Shift+B)

- `backup` 아래 날짜 폴더(`backup-copy.log` 가 있는)를 고르면 기록(대상 폴더, `복사`/`Copied` 줄)과 백업 폴더 내용으로 복원 계획을 만든다 (`BackupCopyPlan.BuildRestore`).
  백업한 파일은 대상으로 되돌리고, 그때 새로 생긴(백업이 없는) 파일은 `Removals` 로 치운다.
- 실행은 같은 `BackupCopyOperation`: 덮어쓰는 지금 파일과 치우는 파일은 **`backup\last_one`** 으로 (그 폴더에도 기록 → 거기서 다시 복원하면 원래대로). 이전 `last_one` 은 휴지통으로.
- 점검: `IoProbe --restore` (백업 복사 → 복원(실행 중인 새 exe 도 치움) → last_one 에서 다시 복원).

## FTP / WebDAV 직접 연결

- **연결 관리 (Ctrl+F, 툴바 지구본 버튼)**: 연결 추가 / 편집 / 삭제 / 연결. 등록한 연결은 드라이브 목록에 🌐 로도 나온다.
- 종류: **FTP**, **FTPS (명시적 TLS)**, **WebDAV (http/https)**. SFTP(SSH) 는 지원하지 않는다.
- 경로: `ftp://연결이름/폴더`, `dav://연결이름/폴더`. 경로 입력란·명령줄 `cd` 로도 이동할 수 있다.
- 지원: 목록, 복사·이동(F5/F6, 드래그 앤 드롭) — PC↔원격, 원격↔원격(FTP→WebDAV, 폰→FTP 등, PC 임시 파일 경유),
  새 폴더, 이름 바꾸기, 삭제(휴지통 없음 → 영구 삭제), F3/F4/Enter(임시 사본으로 열기).
- WebDAV 는 서버가 알려 주면 **실제 여유 공간**(quota)을 표시한다 (Windows 의 WebDAV 드라이브 연결은 C: 용량을 보여 주는 문제가 있음).
- 비밀번호는 `%APPDATA%\MP-Commander\connections.ini` 에 **Windows DPAPI(현재 사용자)** 로 암호화해 저장 → 다른 계정·PC 에서는 풀 수 없다.
- 자체 서명 인증서를 쓰는 NAS 는 연결 설정에서 "인증서 오류 무시"를 켠다 (그 연결의 서버에만 적용).
- **먹통 방지**: 요청 전에 서버 포트로 2초 TCP 확인, 응답·데이터가 **5초** 동안 없으면 요청을 끊고 그 서버를 잠시 "응답 없음"으로 표시해 바로 실패시킨다.
- 시험: `IoProbe --remote` (로컬 FTP 127.0.0.1:60021, WebDAV http://127.0.0.1:8088/dav 필요), `IoProbe --stall` (응답 없는 서버).

## 안드로이드폰 (MTP)

- USB 로 연결한 폰이 드라이브 목록 끝에 `📱 기기이름` 으로 나온다. 경로는 `mtp://기기이름/저장소/폴더`.
- 폰에서 잠금을 풀고 USB 연결 알림에서 **파일 전송** 을 골라야 저장소가 보인다.
- 지원: 목록, 폰↔PC 복사·이동(F5/F6, 드래그 앤 드롭), 폰↔폰 복사(임시 파일 경유), 새 폴더, 이름 바꾸기(기기가 지원할 때), 삭제(휴지통 없음 → 영구 삭제), 여유 공간.
- F3/F4/Enter 는 임시 폴더로 받아서 연다. F4 로 고친 파일은 자동으로 폰에 올라가지 않는다.
- 지원 안 함: 파일 찾기(Alt+F7), 터미널, 자동 새로고침.
- 먹통 방지: 폰 작업은 10초 동안 진행이 없으면 타임아웃, 기기 작업을 취소하고 다음 접근 때 다시 연결한다.
- USB 메모리·외장 디스크도 Windows 가 WPD 로 함께 보여 주지만, 이미 드라이브 문자가 있으므로 목록에서 뺀다.
- C++ `FmMtp.cpp` 가 WPD API 를 쓴다. 목록 속성은 대량 조회(IPortableDevicePropertiesBulk) 로 한 번에 받는다.

`IoProbe --mtp` (기기 목록·저장소 확인), `IoProbe --mtp-roundtrip <기기이름>` (폰에 테스트 폴더를 만들어 왕복 복사 후 지움).

## 폴더 히스토리

- 폴더를 옮기면 떠난 폴더가 **최근 폴더** 맨 앞에 들어간다 (모든 패널 공용, 중복 제거, 최대 `MaxHistory` 개).
- 패널이 각 폴더에 머문 시간과 방문 횟수를 기록해 **자주 머문 폴더**(스마트 히스토리) 상위 `SmartCount` 개를 메뉴 맨 위에 따로 보여 준다.
  - 점수 = (체류 분 + 방문수 × 0.5) × 0.5^(마지막 방문 후 일수 / `SmartHalfLifeDays`)
  - 한 번 방문의 체류 시간은 `MaxDwellMinutesPerVisit` 분까지만 인정 (켜 두고 퇴근해도 왜곡되지 않게)
  - 2회 이상 방문했거나 1분 이상 머문 폴더만 후보. 스마트 목록에 있는 폴더는 최근 목록에서 뺀다.
  - 레이아웃에서 숨겨진 패널은 시간을 세지 않는다.
- **별표 버튼 (경로 입력란 옆 ☆, Ctrl+D)**: 현재 폴더가 자주 머문 폴더 목록에 있으면 노란 ★ 로 켜진다.
  - 꺼진 ☆ 를 누르면 **고정**으로 올라가 항상 목록 맨 위에 나온다 (`SmartCount` 와 상관없이).
  - 켜진 ★ 를 누르면 목록에서 내리고, 자동 순위로도 다시 올라오지 않는다 (다시 ★ 하기 전까지).
  - 고정·제외 목록은 `MP-Commander.ini` 의 `[Pinned]`, `[Excluded]` 에 저장된다.

## 다국어 (한국어 / English)

- 화면 언어는 **운영체제 언어**를 따른다 (한국어 Windows → 한국어, 그 밖 → English). 설정 창의 **언어 / Language** 에서 바꿀 수 있고, 다시 시작하면 적용된다 (settings.ini `Language` = auto / ko / en).
- 언어 팩: 실행 파일 옆 `lang\<코드>.txt` (UTF-8). 원문(한국어) 한 줄, 다음 줄에 `=> 번역`. `\n` 줄 바꿈, `\t` 탭, `{0}` `{1:N0}` 자리 표시는 그대로.
  `en.txt` 를 `ja.txt` 처럼 복사해 번역하면 언어가 늘어난다 (첫 줄 `#name=` 이 목록에 보이는 이름).
- 코드: 원문을 그대로 키로 쓴다 — `Loc.T("원문")`, 보간 문자열은 `Loc.F($"원문 {값}")` (키는 `{0}` 형식). XAML 글자는 창을 만든 뒤 `LocUi.Apply(this)` 가 바꾼다.
  번역이 없는 문장은 원문이 나온다. `MPC_LANG_MISSING=파일` 로 실행하면 번역이 없는 원문을 그 파일에 모은다.

## 설정

- `%APPDATA%\MP-Commander\MP-Commander.ini` — 히스토리 설정과 기록

  ```ini
  [History]
  MaxHistory=30                 ; 최근 폴더 최대 개수 (5~500)
  SmartCount=5                  ; 자주 머문 폴더 개수 (0 이면 끔)
  SmartHalfLifeDays=14
  MaxDwellMinutesPerVisit=30
  ```
- `%APPDATA%\MP-Commander\settings.ini` — 패널 수·배치·경로·정렬, 창 위치, `Editor`, `Terminal`, 명령줄 기록,
  `[Unblock]`, `[Pack]`, `[BackupCopy]`. 자주 바꾸는 값은 **설정 창**(툴바 톱니바퀴)에서 고친다.
  (0.4.0 이전의 `settings.json` 은 처음 실행할 때 옮겨 오고 `settings.json.migrated` 로 이름을 바꾼다.)
